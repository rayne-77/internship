# 🔵 Blue Gradient Calculator

A stylish calculator built using **HTML, CSS, and JavaScript**, featuring a dark blue gradient design, glowing buttons, and a calculation history panel.

## ✨ Features

- Perform basic arithmetic operations: addition, subtraction, multiplication, and division.
- Calculate using decimal numbers and percentages.
- Display calculation results on the calculator screen.
- Save calculation history using browser `localStorage`.
- View up to 30 previous calculations.
- Click a history item to reuse its result.
- Clear the current calculator input using the **AC** button.
- Enjoy a dark blue gradient theme with cyan borders, glowing effects, and interactive buttons.
- Handle invalid calculations and non-finite results, including division by zero.

## 🛠️ Technologies Used

- **HTML5** — Structure of the calculator.
- **CSS3** — Blue gradients, layout, button styling, borders, shadows, and hover effects.
- **JavaScript** — Calculator operations, button interactions, result handling, and calculation history.
- **Browser localStorage** — Stores calculation history in the browser.

## ⚙️ Setup and Installation

No additional software or libraries are required to run this project.

1. Download or clone this repository.
2. Open the downloaded project folder.
3. Locate the main HTML file.
4. Open the HTML file in a web browser, such as Google Chrome, Microsoft Edge, or Firefox.
5. Start performing calculations!

### Run from GitHub

You can download the project using the **Code → Download ZIP** option on GitHub, extract the ZIP file, and open the HTML file in your browser.

## 🧮 How to Use

1. Enter an expression using the calculator buttons.
2. Press `=` to calculate the result.
3. View previous calculations in the **History** panel.
4. Click a history entry to reuse its result.
5. Press `AC` to clear the current input.

**Note:** Calculation history is stored in your browser. It may not appear in another browser or on another device.
